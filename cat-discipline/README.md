# 🐱 Cat Discipline · 猫咪自律日历

一个猫咪主题的个人自律小应用：**习惯打卡 + 待办事项**，全部清晰标注在月历上。零安装、纯本地运行、数据不出本机。

## ✨ 功能

- 📅 **日历主视图**：月历上同时标出每个习惯的打卡状态（彩色圆点）和待办（完成/未完成/过期徽标）
- 🐾 **习惯打卡**：添加习惯 → 每天一键打卡 → 自动计算连续天数（🔥 streak）→ 支持补打历史日期
- 📝 **待办事项**：四种重复规则——不重复 / 每天 / 每周几（可勾选周一~周日）/ 自选日期；可设置计划时间
- 🔔 **每日提醒**：打开应用时横幅提醒今日未完成事项；可开启浏览器桌面通知
- 📊 **统计反馈**：累计打卡、最长连击、今日完成率、近 14 周打卡热力图、习惯连击排行
- 🐱 **猫咪伙伴**：内嵌 SVG 吉祥物，可命名、可"撸猫"互动
- ⚙️ **个性化**：导出 JSON 备份、一键清空数据

## 🚀 如何运行

直接双击 `index.html` 用浏览器打开即可，无需安装、无需联网。

数据保存在浏览器 localStorage 中（本机），关闭网页不丢失；如需迁移或备份，可在设置页导出 JSON。

## 🛠 技术说明

- 纯 HTML + CSS + JavaScript 单文件应用（无任何依赖、无构建步骤）
- 数据层：localStorage；日期键使用本地时区（避免 UTC 错位）
- 图标：内嵌 SVG sprite 线性图标（Lucide/Feather 风格）
