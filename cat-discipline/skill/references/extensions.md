# 扩展方向（进阶）

> MVP 之外的能力，按需选用。MVP 范围见 `features.md`。

## 1. 真·后台提醒
浏览器方案只在应用打开时弹通知。要「关掉也到点弹」：
- 用 **Electron** 把单文件应用封装为桌面程序，托盘常驻 + 系统通知。
- 或接**系统计划任务/定时脚本**（Windows 任务计划、macOS launchd）拉起提醒。
- 优先级：提醒是「锦上添花」，日历兜底已能覆盖大部分遗漏。

## 2. 日历视图增强
- **周视图 / 日视图 / 议程视图**切换；年视图热力图。
- **拖拽改期**：在日历上拖动待办到另一天改 `date`。
- 周起始日、农历/节假日标注（可选）。

## 3. 更灵活的重复
- **按星期重复**（如每周一三五）、每月指定日。
- 重复规则数据结构升级为 `repeat: { type:'weekly', days:[1,3,5] }`。
- 结束条件：永不 / 日期 / 次数。

## 4. 习惯进阶
- 分类标签（健康/学习/生活）与筛选。
- 目标周期挑战（如 21 天）、失败补偿（补卡续 streak 开关，默认关）。
- 每日目标次数（如「喝水 8 杯」可分次计数，`records[date]` 存数字而非布尔）。

## 5. 成就与报告
- 里程碑徽章（首周、30 天、100 天连击）。
- 周/月报告卡片：完成率趋势、最佳习惯、待办履约率。

## 6. 个性化与多端
- 多宠物/多主题切换（猫/狗/兔，深浅色）。
- 导入备份（与导出对称）。
- 数据云同步 / 多设备（需后端，超出单文件范畴，可单列服务）。

## 7. 工程化（当单文件过大时）
- 拆分为多文件（HTML/CSS/JS 分离）或迁到轻量构建（Vite）。
- 引入 IndexedDB 替代 localStorage（数据量大时）。
- 单元测试覆盖 `streakOf`/`calendarDayState`/`monthMatrix` 等纯函数。
