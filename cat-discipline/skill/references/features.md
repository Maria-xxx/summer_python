# 功能模块规格

> 功能清单与验收标准。**日历主视图（§1）是核心，必须优先实现。** 定位/原则见 `design.md`，数据结构/算法见 `data-model.md`。

## 1. 日历主视图（Calendar · 核心）

月历网格是应用首屏，同时承载习惯与待办的可见性。

### 1.1 月历网格
- 7 列网格，表头为周几（可配置周起始日：周日 / 周一）。
- 每个单元格里：
  - 日期数字；**今天**用天蓝色高亮（描边 + 底色）；**选中日**用另一种高亮与今天区分。
  - **习惯标记**：一行小圆点，每个习惯一色；该日已打卡=实心 ✓，未打=空心。习惯多时可改为「2/3」数字 + 微进度。
  - **待办标记**：徽标显示当日待办状态——待办数（🔵 天蓝）、已完成数（✅ 薄荷绿）、过期数（⚠️ 暖琥珀）。
  - 有任何活动（打卡或待办）之日给淡底色；空日保持中性。
- 月份导航：‹ › 翻月、「今天」按钮一键回到当月并选中今天。

### 1.2 日期下钻（日详情面板）
- 点击某日 → 在日历旁/下方展开该日详情：
  - 当日习惯列表，每个带一键打卡按钮（可在此直接补打/取消）。
  - 当日待办列表，带完成切换 + 计划时间；过期待办用警告色提示。
  - 快速新增：在当日直接添加「安排到这一天的待办」。

### 1.3 图例与可读性
- 提供图例说明圆点/徽标含义；保持单元格在小尺寸下仍可辨（必要时数字优先于圆点）。

**验收**：月历首屏可见；今天高亮；单元格同时显示当日习惯完成度与待办状态；点日可下钻并在当日补打/完成；翻月与回今天正常。

## 2. 习惯打卡（Habits）

- 添加 / 删除习惯，自动分配可爱图标与代表色。
- **每日一键打卡 / 取消**，打卡有动画 + toast；可从日历单元格或日详情补打历史日（谨慎：补打允许，但 streak 以连续真实日为准）。
- **连续天数（streak）🔥**：核心激励指标，自动计算（见 `data-model.md`）。
- 历史按日期存储（`records: { "YYYY-MM-DD": true }`）；日历与热力图都基于它。
- 习惯列表页（次要）：展示每个习惯的 streak、最近 7 天迷你日历、代表色。

**验收**：增删习惯；当日打卡可切换；streak 正确；日历单元格反映打卡；可补打历史日。

## 3. 待办事项（Todos）

- 添加待办时**指定日期**（默认今天）；可设计划时间 ⏰。
- **重复规则**（四选一，非"不重复"时跨天自动重置完成态）：
  - **不重复**（none）：仅出现在 `date` 那天，单次待办。
  - **每天**（daily）：出现在日历每一天。
  - **每周几**（weekly）：勾选 1–7 个星期，仅命中那天出现。
  - **自选日期**（custom）：勾选若干个日期，仅这些天出现。
- 完成 / 取消（完成态置灰 + 划线 + 完成日期记录）。
- **过期处理**：仅"不重复"且日期早于今天且未完成 → 日历单元格与详情里用警告色标记「过期」；重复类只在命中日显示，不标过期。
- 日历单元格显示当日待办计数与完成进度。
- 待办列表页默认显示「今日命中」，可切换「显示全部」。

**验收**：四类重复都能正确在日历/列表出现与计数；跨天重置正常；过期高亮仅对单次未完成生效。

## 4. 每日提醒（Reminder）

- **进入应用横幅**：列出今天尚未完成的待办（开关可控）。
- **浏览器桌面通知**：授权后，打开应用且有未完成待办时弹系统通知。
- **日历兜底**：即便错过通知，打开应用即见过期/今日待办在日历上高亮。
- 进阶（非浏览器方案）：系统级后台提醒需 Electron 封装或系统计划任务，见 `extensions.md`。

**验收**：进入时横幅列出今日待办；桌面通知授权流程正常；过期项在日历可见。

## 5. 统计与反馈（Stats）

- 累计打卡次数、最长连续天数、今日/本月习惯完成率。
- 近 N 周打卡**热力图**（所有习惯合计，按密度分级配色）——本质即一种日历视图。
- 各习惯最长连续排行；本月「有活动天数」覆盖率。

**验收**：四项指标正确；热力图与日历口径一致（同一日期键）。

## 6. 个性化（Personalization）

- 猫咪命名（显示在主页/日历角）。
- 撸猫互动（点击切换开心表情）。
- 淡天蓝色主题；预留多主题/多宠物扩展。

**验收**：命名生效；撸猫有表情切换反馈。

## 7. 数据管理（Data）

- localStorage 单键读写；提供「导出 JSON 备份」与「清空全部数据」（二次确认）。
- 导入备份可作为扩展项（见 `extensions.md`）。

**验收**：刷新不丢；导出可下载 JSON；清空需二次确认并清空所有模块。
