# 设计基线 · 定位与原则

> 本层定义产品方向与设计语言。功能细节见 `features.md`，数据与算法见 `data-model.md`。

## 1. 产品定位

一款主打「可爱 + 陪伴感」的**个人自律工具**，**以日历为核心视图**：把习惯打卡和待办安排都清晰标在一张月历上，让用户一眼看到自己的自律全貌。核心不是功能堆砌，而是用一只虚拟猫咪伙伴降低「坚持」的枯燥与压力，把自律变成被陪伴的日常仪式。

- **形态**：PC 端优先，浏览器双击即用，零安装、零后端。
- **数据**：全部存本地（localStorage），隐私不出本机。
- **情绪价值**：萌系视觉 + 即时正反馈（连击、动画、撸猫），把「自律」从说教变成陪伴。

## 2. 目标用户与使用场景

| 用户 | 痛点 | 应用如何帮助 |
|------|------|--------------|
| 想培养习惯但易放弃的人 | 缺乏持续激励、看不到坚持的形状 | 日历上连成片的打卡、🔥 连击、热力图 |
| 办公/学习人群 | 每日待办易遗漏、计划与执行脱节 | 待办按日期标在日历上、过期高亮、每日提醒 |
| 喜欢萌系/被陪伴激励的人 | 普通效率工具冷冰冰 | 猫咪伙伴、可命名、撸猫互动 |

## 3. 核心理念：日历即主舞台

- **统一视图**：习惯（每日打卡）与待办（按日期安排）在同一张月历上呈现，互不割裂。
- **一眼可读**：月历单元格里用小圆点/小数字同时表达「今天几个习惯打了」「今天有几件待办、完成几件、过期几件」。
- **可下钻**：点某天 → 展开当日详情（当日习惯打卡 + 当日待办 + 快速增删），日历即入口。

## 4. 设计原则与关键决策

1. **单文件 HTML**：无构建、无依赖、双击即用，便于分发与本地运行。
2. **localStorage 持久化**：关闭网页不丢失；提供「导出 JSON 备份」与「清空数据」。
3. **日历优先**：月历是默认首屏，习惯/待办标记必须在小单元格里清晰可辨。
4. **反馈即时化**：任何操作都有可见反馈（打卡动画、toast、单元格里连击数字/状态即时变化）。
5. **数据可控**：导出 / 清空让用户掌握自己的数据。
6. **本地时间**：日期键一律用本地时间生成，避免 UTC 跨天错位（见 `data-model.md`）。

## 5. 视觉语言

- **主色调**：很淡的天蓝色（`#f0f7ff` 底 → `#e3f2fd` 渐变），白色圆角卡片，柔阴影。整体清爽温柔、不刺眼。
- **强调色**：天空蓝 `#7ec8e3`（浅）→ `#4fa8d5`（深），用于按钮、今天高亮、连击数字等。
- **辅助色**：薄荷绿 `#6fceaa`（完成/打卡成功）、柔珊瑚 `#ffb3c1`（猫咪腮红/温馨）、暖琥珀 `#ffd4a3`（过期警告），在蓝底上做功能区分。
- **吉祥物**：内嵌**可爱猫咪 SVG**——圆耳朵、大眼睛带高光、胖腮红、小肉垫、短尾巴、胡须、可命名；互动（撸猫）切换表情（开心/日常），作为情绪锚点。
- **日历单元**：今天用天蓝描边 + 底色高亮；选中日区别于今天；有活动之日给淡淡蓝底，空日保持中性白。
- **标记系统**：习惯用彩色小圆点（每个习惯一色，已打=实心/未打=空心）；待办用状态徽标（待办数=天蓝、已完成=薄荷绿、过期=暖琥珀警告色）。需配图例。
- **动效**：克制——打卡时单元格里 ✓ 的小弹跳、连击数字递增、撸猫时猫咪变开心表情，避免喧宾夺主。
